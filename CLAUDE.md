# Chess project notes

## Keep the README up to date

Whenever you change behavior that the README describes, update `README.md` in the same change, without waiting to be asked. This includes:

- Commands and aliases (the Commands table, and the command list in the `Chess` docstring in `chess.py`)
- Startup flow and how to run the game
- Board rendering and notation
- Features, and anything added to or removed from Known limitations

Check the README before finishing any task that changes user-visible behavior.
